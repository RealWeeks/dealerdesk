# Product Spec

DealDesk helps car buyers run a disciplined dealership negotiation from a phone. Users create an active car search, discover relevant dealers, track contacts and vehicles, paste dealer updates, review AI-extracted quote details, compare offers, and generate replies.

## MVP scope

- Email/password accounts with JWT authentication.
- One or more user-scoped car searches.
- Manually seeded dealer discovery with radius filtering.
- Search dealers, vehicles, offers, interactions, and tasks.
- AI parsing, call-note summarization, reply generation, and offer analysis through the backend.
- Reviewable AI extraction records before any final offer data is saved.
- Mobile-first Expo interface for the core workflows.

## First use case

The initial seed data supports a buyer in Portland, Maine shopping for a new 2026 Lexus RX 350h Premium AWD within roughly 150 miles.

## Future scope

Live inventory APIs, richer map/geocoding coverage, speech-to-text, screenshots/OCR, payments, subscriptions, dealer CRM integrations, and App Store deployment are intentionally deferred.
